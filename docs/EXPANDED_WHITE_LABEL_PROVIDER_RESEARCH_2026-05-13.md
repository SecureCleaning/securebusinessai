# Expanded White-Label Provider Research

Updated: 2026-05-13

## What We Are Actually Looking For

The ideal provider should let Secure Business AI sell a staged client journey:

1. Start with an AI voice receptionist.
2. Add website chat later.
3. Add WhatsApp, SMS, CRM, booking, or lead follow-up later.
4. Keep the same client knowledge base or training material wherever possible.
5. Stay under the Secure Business AI brand, or at least support a referral/partner model.
6. Offer Australian-sounding voices, even if the company is not Australian.

## Key Finding

The best provider is unlikely to be a pure "website builder + voice + chat" company.

The better model is:

- one white-label **AI agent platform** for the client knowledge base, chat, phone, WhatsApp/SMS, and automation;
- one website platform or build process that embeds/connects that agent.

This keeps the customer experience unified while avoiding a weak website just because the AI vendor happens to offer one.

## Recommended Next Trial Order

### 1. Trial Lety.ai first

Lety is closest to the desired agency product: one white-label platform, client workspaces, all major channels, billing, and claimed voice/chat/SMS/WhatsApp coverage.

Trial questions:

- Can one client knowledge base train both the phone agent and website chat agent?
- Can the voice use a convincing Australian accent?
- Can each client be expanded from voice-only to chat later without rebuilding?
- Can we hide vendor branding everywhere?
- Can it embed cleanly into the current Secure Business AI website and future client websites?
- Does it support booking, lead capture, call summary, transcript, and human handover?

### 2. Trial Stammer AI second

Stammer looks practical for a simple agency launch because it clearly sells white-label chat and voice agents, unlimited clients, API access, and knowledge-base limits.

Trial questions:

- Is the client dashboard polished enough to show customers?
- Can we create one client account and add voice now, chat later?
- Can we choose or configure an Australian voice?
- Is pricing predictable once calls and messages scale?

### 3. Talk to Synthflow and ElevenLabs for higher-quality voice path

These may be better if voice quality matters more than white-label simplicity.

Use them if:

- Lety/Stammer voice quality is not strong enough;
- Australian accent is weak;
- we want deeper custom behaviour;
- larger clients want a more robust voice agent.

## Website Strategy

If the client later wants a full new website, do not force the AI provider to be the website builder unless it is genuinely good.

Better options:

- Build the website in the existing Secure Business AI stack.
- Use GoHighLevel for fast SMB websites if we adopt it as the business platform.
- Use Duda or another website platform later for higher-polish client sites.
- Embed the selected white-label AI agent into any website.

## Suggested Commercial Packaging

### Stage 1: AI Voice Receptionist

For clients losing calls or after-hours enquiries.

Includes:

- phone answering;
- basic lead qualification;
- call summaries and transcripts;
- email/SMS handover;
- training from website, FAQs, service areas, and booking rules.

### Stage 2: Website AI Assistant

For clients who want website visitors to get answers before calling.

Includes:

- website chat widget;
- lead capture;
- quote/booking direction;
- same business knowledge where supported by the vendor;
- escalation to phone, email, booking, or human follow-up.

### Stage 3: Connected AI Front Desk

Voice + chat + SMS/WhatsApp + CRM handover.

This is the strongest recurring package because it feels like a single front desk, not several disconnected tools.

### Stage 4: Website Upgrade

If the existing website is poor, rebuild it and embed the already-trained AI assistant.

## Decision

The next move should be a hands-on trial, not more spreadsheet scoring.

Best first test:

1. Create a trial account with Lety.ai.
2. Build one mock client: a local plumber, cleaner, or dentist.
3. Train it from a small website + FAQ document.
4. Test voice receptionist with Australian-style voice.
5. Add website chat using the same or copied knowledge.
6. Confirm white-label dashboard and customer-facing branding.

If Lety fails on voice quality or knowledge reuse, test Stammer next. If both are too light, move to Synthflow or ElevenLabs and accept that Secure Business AI may need to own more of the white-label wrapper.
